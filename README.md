# Portfolio FATEC

Este repositório reúne a documentação e os projetos desenvolvidos ao longo do curso/disciplinas com o objetivo de registrar aprendizado, apresentar entregáveis e facilitar a avaliação e o compartilhamento do trabalho.

## Intenção

- Documentar os conceitos, exercícios e projetos práticos realizados durante o curso.
- Servir como portfólio técnico que demonstra competências em desenvolvimento de software (APIs, aplicações, documentação, etc.).
- Manter um histórico organizado dos projetos com instruções mínimas para reprodução e leitura do código.

## O que você encontra aqui

- `Introdução.md` — Visão geral e contexto do repositório.
- `Projetos/` — Pastas e arquivos com descrição dos projetos.

Observação: nem todos os projetos precisam conter código executável no repositório; alguns itens podem ser somente documentação ou entregáveis em Markdown.

## Como usar

1. Navegue pelos arquivos Markdown para entender cada projeto e as decisões tomadas.
2. Sempre que um projeto tiver código, procure por um README específico dentro da pasta do projeto com instruções de execução, dependências e exemplos.
3. Para executar ou testar um projeto específico, siga as instruções localizadas no diretório desse projeto. Se não houver instruções, abra uma issue ou contate o autor para solicitar detalhes.
